# 每日AI议题归纳

科学期刊与社媒热点的三个领域保持固定；领域内部的议题由每日ChatGPT编辑任务阅读当期窗口中的记录后生成。议题名称、成员及一句要点保存在当日分析文件中，不由关键词规则固定。前端只筛选日期、排序和显示原文，构建脚本只核对归属并计算条目数/来源数。

## 每日流程

1. 完成两个栏目的当日JSON以及公开来源元数据更新。
2. 运行`python3 scripts/prepare_topic_input.py --date YYYY-MM-DD --output /tmp/brief-topic-input.json`。此步骤生成当期全部记录、输入指纹和上一期议题，允许已有分析过期时重新取得输入。
3. 按领域阅读全部输入，以具体问题、技术方向或连续进展聚类。参考上一期语义相同的议题，沿用ID和可辨识名称；新问题使用新ID，过期且已无成员的议题不继续输出。
4. 写入`data/topic-analysis/YYYY-MM-DD.json`，使用下面的格式。两个栏目各自归纳；不要直接复用旧分类或强制每个领域恰好几个议题。每组至少有两条不同原始内容，摘要引用须属于该组。只读到标题时，应归纳内容方向，不推测正文结论。无法合理归组的记录逐一写入`unassigned_ids`。
5. 运行`python3 scripts/sync_briefs.py`及`python3 scripts/check_social.py`。在来源更新、归组调整或修改成员后重新校验，并提交当日分析文件及更新后的数据。不要在读取输入后继续追加来源而不更新分析。

每条记录只分配一个主要议题，避免跨议题重复计数。多语转载、同一文章重发与同一工具的小版本不能充当多项独立进展的依据。AI可将它们纳入相关议题，但归纳要点应引用不同原始内容；来源数仍由实际记录去重计算。

只有GitHub工具、不能运行本地脚本时，先从最新main创建`draft/brief-YYYY-MM-DD`分支，在该分支一次写入待发布的两栏JSON及核查元数据。推送会自动运行`Prepare AI topic input`，完成后读取该草稿分支的`data/topic-input/YYYY-MM-DD.json`。AI据此写出分析文件，最终在最新main上一次提交已核对的当日JSON、元数据及`data/topic-analysis/YYYY-MM-DD.json`。输入文件仅用于草稿阶段，不必复制到main。草稿不会发布到网站；只有完整资料进入main后才触发正式部署。若草稿分支已存在，先核对其内容与最新main，再更新，不能把过时来源直接当作本期输入。

## 分析文件

```json
{
  "version": 1,
  "date": "YYYY-MM-DD",
  "generated_at": "YYYY-MM-DDTHH:MM:SS+08:00",
  "generated_by": "ChatGPT",
  "channels": {
    "journal": {
      "start": "从输入复制",
      "end": "从输入复制",
      "source_fingerprint": "从输入原样复制",
      "topics": [{
        "id": "语义稳定的小写英文连字符ID",
        "domain": "运动科学",
        "label": "具体议题短标题",
        "summary": "由引用记录支持的一句归纳",
        "confidence": "中",
        "confidence_reason": "说明归纳所依据的内容及证据层级",
        "item_ids": ["输入中的真实记录ID", "同组另一记录ID"],
        "summary_refs": ["支持归纳的记录ID", "另一引用ID"]
      }],
      "unassigned_ids": ["其余所有未归组记录的ID"]
    },
    "social": {
      "start": "从输入复制",
      "end": "从输入复制",
      "source_fingerprint": "从输入原样复制",
      "topics": [],
      "unassigned_ids": []
    }
  }
}
```

`domain`沿用内部键`运动科学`、`运动健康`、`AI`，界面将第一项显示为“运动表现”。`label`为4–24字，建议8–14字；`summary`最多180字，优先一句话。置信度用高/中/低/未知，评价议题归纳和概括的把握，不替代原文自身的研究证据等级。IDs、引用和未归组记录必须完全覆盖当期输入，不能引用旧窗口中已经不存在的记录。

## 呈现与连续性

默认显示所选领域和日期内的三个主要议题，其余通过“更多”打开。“其他已收录内容”排在最后，仅在更多内容中显示。未归组记录仍可逐条访问。主题在所选范围内无成员时从图中消失，日期变化同时重算排序和图格。

点选整个议题可看到原文列表。只有归纳的全部引用都在所选范围内时，才显示该句要点及置信度；点选单日仅显示当天原文，避免把全期概括重复为单日结论。旧分类分享链接映射到当期相关议题，历史日期继续使用自身快照。

2026-10-20起的新一期须有对应AI分析。缺失分析或输入指纹过期会使发布检查失败；历史存档继续保留其原有分类依据。任务仍使用原有07:50编辑流程，不新增模型API或独立任务。
